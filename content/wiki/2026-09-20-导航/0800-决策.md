## 简介

| 层级 | 负责的问题 | 主要工作 |
|---|---|---|
| Nav2导航层 | 给定目标后，怎样到达 | 代价地图、规划器、控制器、重规划和恢复；已有的Nav2 BT属于这里 |
| 上层决策 | 什么时候出发、去哪个点、什么时候取消或换任务 | 自己的任务节点，用状态机或BT组织逻辑 |

## 节点

### 小陀螺

#### 节点

先写节点`cpp`文件，把发布`cmd_spin`写完。

#### 加入action

新建 `behavior_manager/action/ChassisSpin.action`：

内容：

```action
# Goal：任务参数
float32 spin_speed
float32 duration

---
# Result：任务结束结果
bool success
string message

---
# Feedback：执行进度
float32 commanded_speed
float32 elapsed_time
```

| 字段 | 含义 |
|---|---|
| `spin_speed` | 自旋角速度，rad/s，正负决定方向 |
| `duration` | 持续时间，秒；`0` 表示持续到取消 |
| `success` | 是否正常完成指定任务 |
| `message` | 完成或异常说明 |
| `commanded_speed` | 当前发布的自旋速度，**不是实际测得的转速** |
| `elapsed_time` | 已执行时间，秒 |

package.xml 补依赖:

```xml
<buildtool_depend>rosidl_default_generators</buildtool_depend>

<depend>action_msgs</depend>
<exec_depend>rosidl_default_runtime</exec_depend>

<member_of_group>rosidl_interface_packages</member_of_group>
```

cmakelists:

```cmake
find_package(action_msgs REQUIRED)
find_package(rosidl_default_generators REQUIRED)
```

在 `add_executable()` 之前添加：

```cmake
rosidl_generate_interfaces(${PROJECT_NAME}
  "action/ChassisSpin.action"
)
```

在最后的 `ament_package()` 前添加：

```cmake
ament_export_dependencies(rosidl_default_runtime)
```

编译：

```bash
colcon build --base-paths src \
  --packages-select behavior_manager \
  --symlink-install
```

查看接口是否生成：

```bash
source install/setup.bash
ros2 interface show behavior_manager/action/ChassisSpin
```
